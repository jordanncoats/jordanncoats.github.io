# jordancoats.dev

Source for my personal portfolio site: [jordancoats.dev](https://jordancoats.dev)

A lightweight, single-page site built with plain HTML and CSS. No frameworks, no JavaScript and no build step, so it loads fast and works well on mobile.

## Built with

- HTML5 and CSS3
- [Normalize.css](https://necolas.github.io/normalize.css/)
- [Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans) via Google Fonts
- Hosted on GitHub Pages
